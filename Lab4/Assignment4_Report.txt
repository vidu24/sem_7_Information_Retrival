Practical Assignment 4: Search Engine Ranking and Evaluation
Mini Search Engine for a College Library

1. Objective
The program searches a small collection of college-library document descriptions and ranks them for a student's query. It implements TF-IDF scoring, a TF-IDF Vector Space Model using cosine similarity, BM25 probabilistic ranking, and the Binary Independence Model (BIM).

2. Methodology
The dataset contains 12 short document descriptions. Text is converted to lowercase word tokens and common stopwords are removed. Document frequency and smoothed inverse document frequency are calculated. TF-IDF scoring matches query terms against documents; VSM computes cosine similarity between normalized TF-IDF vectors. BM25 combines term frequency, inverse document frequency, and document-length normalization. BIM uses binary term presence and smoothed relevance/non-relevance probabilities based on the supplied relevance judgments.

The Probabilistic Ranking Principle (PRP) states that, under the model's probability estimates and assumptions, documents should be ranked in decreasing order of their probability of being relevant to the query. BM25 is a probabilistic ranking function; BIM assumes term independence and uses binary term presence.

3. Test queries and relevance judgments
Q1: "machine learning applications in healthcare"
Q2: "computer networks and cybersecurity"
Q3: "quantum computing physics"

The Python file contains illustrative relevant-document labels for each query. The assignment asks students to obtain judgments from a teacher or student group. These labels must therefore be reviewed and replaced or confirmed by human evaluators before final submission.

4. Evaluation
For each query, the program prints the top five documents and scores for all four models. It calculates Precision@5, Recall@5, F1@5, MRR@5, AP@5, and NDCG@5. MAP is reported as the mean of AP@5 across the test queries. The console output also prints aggregate metric averages so models can be compared.

5. Observations
The models generally rank documents containing query terms near the top. VSM cosine accounts for vector normalization, while BM25 additionally normalizes for document length. BIM can use relevance feedback, but its ranking depends on the supplied judgments. In this demonstration run, BIM has the strongest aggregate values among the displayed models; this is not evidence that BIM is universally superior because the collection and test set are small and the judgments are illustrative.

6. Limitations
- The document collection is small and uses short, synthetic descriptions rather than a real library catalogue.
- The relevance labels are illustrative and require human confirmation.
- Only three test queries are used.
- BM25 and BIM scores are ranking scores, not calibrated probabilities.
- Tokenization, stopword selection, and query choice affect rankings.
- This is a simple in-memory demonstration, not a production search service.

7. Conclusion
The implementation demonstrates multiple document-ranking approaches and standard information-retrieval evaluation metrics. The output can be used to compare rankings and inspect errors. For a defensible evaluation, collect human relevance judgments for more queries, rerun the script, include screenshots of the output, and discuss the resulting metric differences.
